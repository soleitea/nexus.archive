NEXUS ARCHIVE — Honkai: Nexus Anima fan-made database

Open index.html in a browser to preview the website.
The site is a standalone static HTML project. No server or database is required.
For GitHub Pages: create a repository, upload index.html (or upload the contents of this folder),
then enable Pages from the main branch / root folder.
